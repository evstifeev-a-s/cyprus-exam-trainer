# Кипр: тренажёр к экзамену

Тренажёр к экзамену на знание Кипра (культура и реалии): 490 карточек, план до даты экзамена, связки, «Верно или нет», словарь.

Открыть: https://evstifeev-a-s.github.io/cyprus-exam-trainer/

Прогресс хранится в браузере на устройстве. На iPhone добавь страницу на экран «Домой» и занимайся только оттуда.
